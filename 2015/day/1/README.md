## 第一日：這不是 Lisp
聖誕老公公向來都在積了白雪的聖誕日散播祝福，但是這次，他的氣候機器的「降雪」功能須倚靠星星加以驅動，而他的星星已經耗盡。為了拯救這個聖誕節，他需要你在 12 月 25 日之前蒐集五十顆星星。

現在，你幫聖誕老公公解答以下難題，以收集星星。伴隨著降臨節日曆的每一天，有兩顆難題之星星可供你取得，你須先解決第一題，然後能解除第二題之封鎖。每一則難題給予你一顆星星。那麼，加油吧！

以下是簡單的熱身題。

聖誕老公公正在試著給一幢公寓大樓發送禮物，但是，他找不到正確的樓層。他搞不清楚路線指引。他從地面層 (第` 0 `層) 開始，並依循著下列指引，一次由一個符號表示。

每一個開放括號` ( `表示他須往上走一層樓。每一個關閉括號` ) `表示他須往下走一層樓。

那一幢公寓相當高聳，而且地下室也相當深邃，使他無法找到頂層或最下層。

以下為例：

+ `(()) `與` ()() `都將使他回到樓層` 0`。
+ `((( `與` (()(()( `都將使他上到樓層` 3`。
+ `))((((( `也會將他帶到樓層` 3`。
+ `()) `與` ))( `都將他帶往樓層` -1 `(第一層地下層)。
+ `))) `與` )())()) `都使他最後站在樓層` -3`。

問路線指引將聖誕老公公帶到 **哪一層** 呢？

### --- 第二部分 ---
現在，依據同一份路線指引，找出其中第一次出現的指引符號將他第一次帶到地下室 (樓層` -1`) ，該符號的所在 **位置** 是這份路線指引的第幾個符號？如果是指引手冊的第一個符號，位置為` 1`，而第二個符號的位置是` 2`，以此類推。

例如：

+ `) `是用第` 1 `個符號使他下到地下層。
+ `()()) `在第` 5 `個符號使他進入地下層。

使聖誕老人開始踏入地下層的第一次出現的指引符號，是 **第幾個** 符號呢？
