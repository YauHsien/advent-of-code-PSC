## 理想的長襪填充物

聖誕老公公想要挖一些降臨幣 (與比特幣雷同的東西)。他打算將虛擬貨幣當作禮物，送給一些對經濟有些想法的小朋友。

為了達成，他須找出開頭為 **五個零** 的十六進制 MD5 雜湊值。作成 MD5 雜湊值的輸入值是一個密碼後接著一個十進制數 (如你的輸入檔內容)。你須幫聖誕老公公找出最小的足以產生一個雜湊值的正數值，即除去開頭的零，而挖到降臨幣。

以下為例：

+ 如果密碼為` abcdef`，結果將是` 609043`，因為` abcdef609043 `的 MD5 雜湊值為` 000001dbbfa... `且為最小足以求值的正數值。
+ 如果密碼為` pqrstuv`，則能產生開頭帶有五個零的 MD5 雜湊值的後段最小正數值為` 1048970 `，也就是說，` pqrstuv1048970 `的 MD5 雜湊值是` 000006136ef...`。
