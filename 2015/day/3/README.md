## 真空中的完美球形屋

座落在一片無垠的二維方格裡的房子，是聖誕老公公的禮物送達目的地。

聖誕老公公從他的出發點開始，向一棟房子發送禮物，然後，位於北極總部的一名小精靈用無線電呼叫為他指引下一步走法。移動之指引都是向北 (`^`) 找下一間房子，或者向南 (`v`)、向東 (`>`)、向西 (`<`)。聖誕老公公每經移動一步之後，便向他新抵達地點的房子發送禮物。

然而，那位於北極的小精靈喝蛋奶酒喝得稍微多了，有些分不清楚方向，使得聖誕老公公再次拜訪了幾棟房子。那麼，有多少棟房子收到了 *至少一份禮物* 呢？

以下為例：

+ `> `使聖誕老公公給兩棟房子發送禮物：一棟位於出發點，而另一棟在東邊。
+ `^>v< `使他給四棟排成四方形的房子發送禮物，出發點兼為終點收了禮物兩次。
+ `^v^v^v^v^v `使兩棟房子幸運地收到一大堆禮物。
