## 第二日：聽說沒有數學
由於包裝紙快要用完了，小精靈們須發送訂購單，採購包裝紙。他們想要購買與現有的包裝紙徹底相同的尺寸，那些包裝尺寸為一列三維座標 (長` l`、寬` w`、高` l`)。

幸運的是，每一份禮物都是一個盒子 (完美的[正長方稜形](https://www.cuemath.com/geometry/right-rectangular-prism/))，使得容易計算所需的包裝紙：盒子的表面積為` 2*l*w + 2*w*h + 2*h*l`。小精靈們還需要給每一份禮物加一片紙張，尺寸須有最小邊長的平方面積。

以下為例：

+ 具有` 2x3x4 `維度的禮物需要的包裝紙為` 2*6 + 2*12 + 2*8 = 52 `平方呎，加上` 6 `平方呎的保留，總共有` 58 `平方呎。
+ 具有` 1x1x10 `維度的禮物需要的包裝紙為` 2*1 + 2*10 + 2*10 = 42 `平方呎，加上` 1 `平方呎的保留，總共有` 43 `平方呎。

小精靈們給的尺寸清單都是以呎為計量單位。他們須訂購總共 **多少平方呎的包裝紙** 呢？
