## 第二日：禮物店

你進入總部，搭乘電梯，徑來到另一站，那是一家禮物店。「歡迎光臨北極！」牆上有標語興高采烈地歡迎你，而雖然你不知道究竟誰那麼受到容許，能一踏北極公司總部，但你知道你已經抵達此地，站在大廳，你能任意探索北極總部的各處。

當你瀏覽著琳琅滿目、令人驚喜的多樣選擇時，一位店員注意著你，並開口詢問是否為你服務。

而在此時，有個年幼的小精靈在玩弄著禮物店的電腦，他想要將一大堆無效的產品代碼輸入資料庫。喔，說到辨認產品代碼，你可相當拿手了，不是嗎？

他們已經整理了大多數的產品代碼，但剩下一小部分 (為你的輸入檔) 須由你整理。以下為例：

```
11-22,95-115,998-1012,1188511880-1188511890,222220-222224,
1698522-1698528,446443-446449,38593856-38593862,565653-565659,
824824821-824824827,2121212118-2121212124
```

(其實只有一行文字，而我們幫你列為三段，以便於閱讀。)

以逗點分段的每一個號碼範圍都有 **第一個號碼** 與 **最後一個號碼**，中間以` - `隔開。

你觀察那位年輕小精靈的操作，有一種固定模式，**無效的商品代碼** 是指代碼裡包含重複出現的數列，例如` 55 `(`5 `出現兩次)、`6464 `(`64 `出現兩次)、`123123 `(`123 `出現兩次) 都是無效的代碼。

數值不由零開頭，例如` 0101 `根本不是商品代碼。(而` 101 `則是 **有效** 的商品代碼，你毋需多慮。)

你的任務，在號碼範圍的輸入文字裡頭，找出無效的商品代碼。由以上例子，我們看到：

+ `11-22 `有兩個無效代碼` 11 `與` 22`。
+ `95-115 `有一個無效代碼` 99`。
+ `998-1012 `有一個無效代碼` 1010`。
+ `1188511880-1188511890 `有一個無效代碼` 88511885`。
+ `222220-222224 `有一個無效代碼` 222222`。
+ `1698522-1698528 `沒有無效代碼。
+ `446443-446449 `有一個無效代碼` 446446`。
+ `38593856-38593862 `有一個無效代碼` 38593859`。
+ 其他號碼範圍內沒有無效代碼。

將以上的無效代碼的數值相加，總和為` 1227775554`。

**當你將無效代碼的數值加總之後，數有多少？**
