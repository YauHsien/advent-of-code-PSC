## 第十二天：聖誕樹栽種場
你快要趕不上時間了，但剩下須做裝飾的也不多。雖然在這裡沒有樓梯、電梯、手扶梯、隧道、滑道、傳送機、滑降桿、電路等之類的設備，讓你進入北極總部，但是這裡**有**一個通風管道。你立即跳進去。

在管道裡碰撞了好幾分鐘之後，你發現自己置身於寬敞、明亮、滿是聖誕樹的洞穴裡！

有幾個小精靈正在搶著在終止時間以前，瘋狂地做裝飾。她們認為她們能完成大部分工作，不過，她們還擔心一件事：要給住在北極這裡的年幼小精靈們的**禮物**可能還沒準備好。以傳統來講，要在聖誕樹下擺放禮物，但是，小精靈們擔心禮物不**適合**。

聖誕禮物有一套奇怪的標準規格，禮物與其適合擺放的區域，都要用標準的**衡量單位**來量測。為了具備美感，禮物必須放在符合標準化衡量單位的二維網格之中，並且，禁止疊放禮物。

如以往的，小精靈們為你提供資訊報告 (為你的輸入檔)。報告中，首先提供一系列禮物形狀，其次，提供了每一棵樹下的擺放區域尺寸，以及一列每個區域須符合的禮物數量。以下為例：

```
0:
###
##.
##.

1:
###
##.
.##

2:
.##
###
##.

3:
##.
###
##.

4:
###
#..
###

5:
###
.#.
###

4x4: 0 0 0 0 2 0
12x5: 1 0 1 0 2 2
12x5: 1 0 1 0 3 2
```

第一部份列出禮物的標準**形狀**。為了方便使用，每一個形狀先有一個**代號**後接一個冒號，然後，用視覺呈現禮物的形狀，` # `為形狀的範圍而` . `不是。

第二部份列出每一棵樹下的**區域**。每一筆開始寫著區域的寬度與長度，例如` 12x5 `是寬度` 12 `個單位，而長度` 5 `個單位的區域。同一行之後的部份，列出能符合這個區域的**各種形狀禮物的數量**，例如` 1 0 1 0 3 2 `意味你要放一個形狀` 0 `的禮物，不放形狀` 1 `的，然後一個形狀` 2 `的禮物，不放形狀` 3 `的，接著三個形狀` 4 `的禮物，以及兩個形狀` 5 `的禮物。

禮物可以**旋轉**，也可以**翻面**，只要能擺進區域裡，但是，禮物都必須工整地放滿網格。不同個禮物的形狀不可以交疊 (也就是說，兩個禮物的任何兩個` # `部位不可以存在於區域裡的同一個位置)，但可以契合 (也就是說，一個禮物的` . `部位不會妨礙另一個禮物佔據它的位置)。

小精靈們想要知道**有多少個區域**適合所列的各種禮物。如以上例子，有六種形狀的禮物，要比對三個區域。

第一個區域` 4x4 `：

```
....
....
....
....
```

在這個區域裡，你須檢查是否適合兩個形狀` 4 `的禮物：

```
###
#..
###
```

經過幾次常式，**能**用下列方式，使兩個禮物符合這個區域。以下為其中一種例子，` A `表示其中一個禮物，另一個禮物是` B `：

```
AAA.
ABAB
ABAB
.BBB
```

第二個區域` 12x5: 1 0 1 0 2 2 `有` 12 `個單位寬、` 5 `個單位長。在這個區域裡，你必須試著用形狀` 0 `一個、形狀` 2 `一個、形狀` 4 `兩個，以及形狀` 5 `兩個來確認是否適合。

結果**能**用以下方式填滿這個區域。這次也用不同的大寫字母表示每個禮物：

```
....AAAFFE.E
.BBBAAFFFEEE
DDDBAAFFCECE
DBBB....CCC.
DDD.....C.C.
```

第三個區域` 12x5: 1 0 1 0 3 2 `有相同的區域大小，而確認適合的禮物形狀多了一個形狀` 4 `的。這次很不幸，不管你怎麼努力，在這個區域就**沒能擺下全部禮物的辦法。**

所以，以上例子有` 2 `個區域能讓全部所列的禮物都填滿。

請你想想每一棵樹與小精靈們希望在樹下擺放的禮物，**有多少個區域能擺得下全部所列的禮物？**
