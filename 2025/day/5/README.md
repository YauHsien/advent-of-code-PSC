## 第五日：餐廳

堆高機衝破了牆壁，而小精靈們很高興，她們終於看到了牆壁另一邊的餐廳。

從廚房裡傳出一陣騷動，「照這個步調，我們可能來不及在餐廳擺放花圈。」而你聽了這話，決定要展開調查。

「假如我們在聖誕日之前，尚未改換為新型庫存管理系統。」有位小精靈喊叫著。於是，你詢問她怎麼回事。

廚房裡的小精靈們繼續說明情況：由於新型庫存管理系統很複雜，她們無法判定哪些食材**還算新鮮**而那些食材**已經壞了**。你詢問系統如何運作，而她們給你一份資料庫的副本 (為你的輸入檔)。

這份資料庫使用**食材代號**，以若干**新鮮食材的號碼區間**，接著空一行，然後是一堆**可取用的食材代號**：例如，

```
3-5
10-14
16-20
12-18

1
5
8
11
17
32
```

新鮮食材的號碼區間包含最後的數值：區間` 3-5 `意味幾個食材代號` 3`、`4`、`5 `都是**新鮮的**。區間範圍可以**重疊**。而只要任何一個食材代號落在**任何一個**區間裡，那個食材就是新鮮的。

小精靈們想要判斷哪些**可取用的食材代號**也是新鮮的食材代號。以上例子，可由以下方式處理：

+ 代碼` 1 `的食材不在任何一個號碼範圍裡，所以是壞的。
+ 代碼` 2 `的食材落在範圍` 3-5 `裡，是**新鮮的**。
+ 代碼` 8 `的食材壞掉了。
+ 代碼` 11 `的食材落在範圍` 10-14 `裡，是**新鮮的**。
+ 代碼` 17 `的食材落在範圍` 16-20 `和` 12-18 `裡，是**新鮮的**。
+ 代碼` 32 `的食材壞掉了。

於是，本例有` 3 `個可用且新鮮的食材。

請你分析新型庫存管理系統的資料庫檔案，**有多少個可用的食材代碼還是新鮮的？**
