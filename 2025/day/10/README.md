## 第十日：工廠
穿過影廳之後，你抵達工廠。幸運地，這裡的小精靈們有許多時間來得及做裝飾，恰因為工廠的機器都停擺。沒有任何一位小精靈能找出啟動機器的辦法。

小精靈們有一本機器手冊，但敘述啟動程序的段落被[柴犬](https://en.wikipedia.org/wiki/Shiba_Inu)啃咬了。手冊剩下的部份包括了指示燈圖示，按鈕電路走線表，以及每一台機器所需的[振盪數](https://adventofcode.com/2025/day/3)。

以下為例：

```
[.##.] (3) (1,3) (2) (2,3) (0,2) (0,1) {3,5,4,7}
[...#.] (0,2,3,4) (2,3) (0,4) (0,1,2) (1,2,3,4) {7,5,12,7,2}
[.###.#] (0,1,2,3,4) (0,3,4) (0,1,2,4,5) (1,2) {10,11,11,5,10,5}
```

手冊以每一行敘述一台機器。各行用`[`方形括號`]`包含一個指示燈圖示，以及好幾個用`(`括弧`)`表示的電路走線表，最後用`{`大括弧`}`表示需要振盪數。

為了啟動機器，**指示燈**必須符合圖示，用` . `表示**熄燈**而` # `表示**亮燈**。那一台機器正是都有全部的指示燈，但是**一開始**指示燈都是**熄燈的**。

所以，當指示燈圖示為` [.##.] `時，意味有四個指示燈，一開始全部熄燈，而最終須同時讓第一個指示燈熄掉，第二個亮燈，第三個亮燈，第四個熄燈。

你能**切換**指示燈的狀態，辦法是按下一堆**按鈕**。每個切換指示燈的按鈕，` 0 `表示第一個指示燈，` 1 `表示第二個指示燈，以此類推。當你按下按鈕，指示燈如果原先是熄燈的，就會亮燈，而若指示燈原先是亮燈，就會熄燈。你必須按每個按鈕幾次，次數皆為整數；不會有所謂「按下 0.5 次」，也不會有按下負數次。

所以，一顆按鈕的電路走線圖，例如` (0,3,4) `，意味當你按一下這個按鈕，則第一個指示燈、第四個指示燈、第五個指示燈都會亮燈或熄燈。如果指示燈現在是` [#.....] `，則當你按下按鈕，燈號變成` [...##.] `。

因為現在沒有一台機器正在運行，需要振盪數尚且無關，可以徹底忽略。

你能任意數次按下一顆按鈕，不過，為了節省時間，你須決定**總共最少要按下多少次**能正確地控制所有的指示燈，呈現如你手冊所列的燈號。

第一台機器有幾種作法能達到正確的設置：

```
[.##.] (3) (1,3) (2) (2,3) (0,2) (0,1) {3,5,4,7}
```

+ 你可以按前三個按鈕各一下，總共按了` 3 `次。
+ 你可以按` (1,3) `一次，` (2,3) `一次，` (0,1) `兩次，總共按了` 4 `次。
+ 你可以按全部除了` (1,3) `的按鈕各一次，共按了` 5 `次。

但是，最少須按到` 2 `個按鈕，其中一種辦法是按下最後兩個按鈕` (0,2) `與` (0,1) `各一次。

第二台機器最少按` 3 `個按鈕：

```
[...#.] (0,2,3,4) (2,3) (0,4) (0,1,2) (1,2,3,4) {7,5,12,7,2}
```

其中一種辦法是按下最後三顆按鈕` (0,4) `、` (0,1,2) `、` (1,2,3,4) `各一次。

第三台機器有六個指示燈：

```
[.###.#] (0,1,2,3,4) (0,3,4) (0,1,2,4,5) (1,2) {10,11,11,5,10,5}
```

最少須按的按鈕次數為` 2 `，其中一種按法為` (0,3,4) `與` (0,1,2,4,5) `各一次。

所以，總共須設定全部機器指示燈的最少按鈕數為` 2 + 3 + 2 =`**` 7 `**。

請你分析每一台機器的指示燈圖示以及按鈕電路走線圖，**正確地配置全部機器指示燈的最少按鈕數為多少？**
