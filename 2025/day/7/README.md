## 第七日：實驗室
你向那一家子頭足類動物道謝，便離開了垃圾壓縮廠，前去尋找北極總部那做[熟悉](https://adventofcode.com/2024/day/6)的[穿堂](https://adventofcode.com/2018/day/4)，通往實驗棟。

大大的標語寫著「傳送站」，看起來她們已經研發了**傳送**技術，你等不及要親自上去試試，於是，你踏上了寬廣的黃色傳送平台。

但是，你發現自己突然現身於一間陌生的房間！房間沒有門，唯一的出口要靠著傳送機。但不幸地，傳送機看起來已經冒著[青煙](https://en.wikipedia.org/wiki/Magic_smoke)。

由於這裡是傳送機實驗室，到處都放著備用零件以及手冊，還有檢測設備。你將一個檢測器接上，上面顯示了` 0H-N0 `，意思明顯是「超光速粒子流形有誤」。

你趕快檢閱超光速粒子流形一覽圖 (為你的輸入檔)，一道粒子射線由` S `處打進流形。超光速粒子都會**向下**行進。射線會在空間 (`.`) 中自由前進。不過，當射線撞到分解器 (`^`) 時，光束受到阻擋，然後，在分解器的左右兩端立即產生兩道射線。

以下為例：

```
.......S.......
...............
.......^.......
...............
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

超光速粒子的入射射線 (`|`) 由` S `處向下撞到第一個分解器：

```
.......S.......
.......|.......
.......^.......
...............
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

此時，原先的射線停止，而從分解器發出兩道新射線：

```
.......S.......
.......|.......
......|^|......
...............
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

兩道射線繼續往下，再分別撞到另外兩個分解器：

```
.......S.......
.......|.......
......|^|......
......|.|......
......^.^......
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

這次，兩個分解器共同產生了**三**道超光速粒子射線，因為在兩個分解器中間的射線會聚為一個：

```
.......S.......
.......|.......
......|^|......
......|.|......
.....|^|^|.....
...............
.....^.^.^.....
...............
....^.^...^....
...............
...^.^...^.^...
...............
..^...^.....^..
...............
.^.^.^.^.^...^.
...............
```

繼續下去，直到所有的超光速粒子射線要嘛在分解器停止，要嘛往下離開流形：

```
.......S.......
.......|.......
......|^|......
......|.|......
.....|^|^|.....
.....|.|.|.....
....|^|^|^|....
....|.|.|.|....
...|^|^|||^|...
...|.|.|||.|...
..|^|^|||^|^|..
..|.|.|||.|.|..
.|^|||^||.||^|.
.|.|||.||.||.|.
|^|^|^|^|^|||^|
|.|.|.|.|.|||.|
```

為了修好傳送機，你須先看懂超光速粒子流形的射線分離性。如上述例子，超光速粒子射線共分解了` 21 `次。

請你分析你手上的流形一覽圖，**射線總共分解了多少次？**
