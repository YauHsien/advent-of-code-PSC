## 第四日：印刷室

你搭乘著電扶梯往下，抵達印刷室。在此的小精靈們顯然都忙著準備過聖誕日，到處都是很大的、一捲一捲的紙張，而牆角有一台大量印刷機，用以處理相當大量的印刷。

這裡用的裝飾很輕鬆：他們採行自製裝飾物。你所該做的，是繼續往北極總部的下層前進，儘管電梯依然在斷線。

「好了，也許我們能幫你下去」，一位小精靈回應你的詢問。「我們知道在後面那道牆的另一邊有一家餐廳，如果我們能穿過那道牆，你就能往下走了。然而，恰好我們的堆高機都在使用，忙著搬運所有的紙捲。」

假如你能幫忙精簡堆高機的工作路線，她們可能擠得出時間來幫你打穿牆壁。

紙捲 (`@`) 放在一面大場地的各處，小精靈們用一張地圖 (為你的輸入檔) 幫助標明每樣物件所在的位置。

以下為例：

```
..@@.@@@@.
@@@.@.@.@@
@@@@@.@.@@
@.@@@@..@.
@@.@@@@.@@
.@@@@@@@.@
.@.@.@.@@@
@.@@@.@@@@
.@@@@@@@@.
@.@.@@@.@.
```

如果一個紙捲的周圍八個格子其中只有**少於四個**紙捲，堆高機才可帶起那個紙捲。只要你能幫忙想出堆高機要帶起哪一個紙捲，能讓小精靈們花費更少的時間整理環境，而獲得更多時間來幫你打穿牆壁。

在這個例子，一輛堆高機能帶起` 13 `捲紙張 (在地圖裡標示為` x`)：

```
..xx.xx@x.
x@@.@.@.@@
@@@@@.x.@@
@.@@@@..@.
x@.@@@@.@x
.@@@@@@@.@
.@.@.@.@@@
x.@@@.@@@@
.@@@@@@@@.
x.x.@@@.x.
```

請你仔細看看整張滿是紙捲的地圖，**一輛堆高機能帶起多少個紙捲？**
