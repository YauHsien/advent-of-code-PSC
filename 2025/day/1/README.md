## 第一日：機密入口
小精靈們獲得兩件消息，一好一壞。

好消息，他們學會了 [專案管理](https://en.wikipedia.org/wiki/Project_management)，使他們不必像以往的聖誕假期之中那麼忙碌。其中一個例子，他們現在知道要盡早做完「北極」公司總部的妝點與整理，以使其他重要的工作都能及時完成。

壞消息，他們發現了另有一件要緊的事情：由於大家都忙著做資源規劃，沒人有空去整理北極。

為了趕上聖誕節，小精靈們請你幫忙去在十二月 12 日之前完成這項妝點與整理北極公司總部的工作。

你須藉由解答以下與後續的難題，以獲取星星。每一天都會有兩道難題，在你解決了第一道難題之後，第二道難題會向你揭示。每一道難題給予你一顆星為獎勵。那麼，祝你好運了！

你抵達「北極」公司總部，站在公司的機密入口之前。你正打算要開始整理時，卻不幸地發現， **密碼** 被誰改掉了，所以你進不去。牆上有張紙，用膠帶黏著，上頭有些說明：

「由於新的安全政策，密碼收錄在下方保險櫃裡。請閱讀附件內容，以獲取新的密碼組合。」

那座保險櫃上安裝了一把數字轉盤，上面有一根指針。盤面依序環繞著` 0 `到` 99 `等數。你撥了撥轉盤，每通過一個數，都發出一聲「咔」。

附件內容 (為你的輸入檔) 列出了一堆轉法，每一項佔了一行，是教你如何開啟保險櫃的辦法。轉法標記以` L `字或` R `字開頭，意思是須將轉盤向 **左** 轉或向 **右** 轉。之後的文字寫了一個數值，代表轉動的 **度數** ，也就是，當你轉動多少的時候，會聽到多少響聲。

假如指針指向` 11 `，轉動` R8 `會使指針轉到` 19 `，而轉動` L19 `接著會讓指針指著` 0`。

由於轉盤是個圓，將轉盤 **從` 0 `向左轉** 使指針指向` 99`。同理，將轉盤 **從` 99 `向右轉** 使指針指向` 0`。

所以，假如指針向著` 5`，轉動` L10 `使指針指向` 95`，並且，再轉動` R5 `則使指針指向` 0`。

現在，指針正向著數值` 50`。

即使你能照著這張紙所說的做，但是，根據你最近所接受的訓練「北極公司正式機密入口安全訓練講座」的教導，你猜那座保險櫃其實是個誘餌。其實密碼是 **在各種旋轉順序之間，當轉盤停止時，指向` 0 `的次數**。

以下列例子，假設附件內容包含了一些轉法：

```
L68
L30
R48
L5
R60
L55
L1
L99
R14
L82
```

照著這些轉法，使轉盤這樣轉：

+ 轉盤一開始指向` 50`。
+ 轉動` L68 `而指向` 82`。
+ 轉動` L30 `而指向` 52`。
+ 轉動` R48 `而指向**` 0 `**。
+ 轉動` L5 `而指向` 95`。
+ 轉動` R60 `而指向` 55`。
+ 轉動` L55 `而指向**` 0`**。
+ 轉動` L1 `而指向` 99`。
+ 轉動` L99 `而指向**` 0`**。
+ 轉動` R14 `而指向` 14`。
+ 轉動` L82 `而指向` 32`。

由於在過程中轉盤指向` 0 `三次，這個例子的密碼是` 3`。

你分析了附件內容，**實際的開門密碼是多少？**
