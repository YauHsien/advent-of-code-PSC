## 第六日：垃圾壓縮

你幫助過廚房的小精靈之後，在休息的時候順便幫她們從新啟動電影放映，但你過於熱切，一躍而跳進垃圾滑槽。

滑行了一陣子，你發現自己身在垃圾粉碎機裡，而且很不幸，大門以磁力封閉著。

你試著找出路，並且見到了一家子頭足類動物！牠們知道怎麼幫你打開大門，但是那需要一些時間。正當你等著牠們時，牠們想問你能不能幫牠們家的小女兒**寫數學作業**。

頭足類動物的數學看起來與普通數學沒差別。在一張算數表裡 (如你的輸入檔) 列出一些**問題**，每一道問題都包含一堆數字，要嘛用**加號** (`+`)彙總，要嘛用**乘號** (`*`)彙總。

只是，那些問題有些奇怪的排列：問題是用水平的方式橫列，列得相當長。以下為例：

```
123 328  51 64
 45 64  387 23
  6 98  215 314
*   +   *   +
```

每一道問題的數值都為縱向排列，而在底端有個須用到的運算符號。兩道相鄰的問題之間，有一道純為空格的縱行加以區隔。至於問題裡的每一筆數值可以靠左或靠右對齊。

所以，這張表有四道問題：

+ `123` * `45` * `6` = **`33210`**
+ `328` + `64` + `98` = **`490`**
+ `51` * `387` * `215` = **`4243455`**
+ `64` + `23` + `314` = **`401`**

要檢查算數結果是否正確時，頭足類動物學生們會將每個問題的解**加總**。如上表，加總為 `33210` + `490` + `4243455` + 401 = **`4277556`**。

當然，真正的算術表是較寬**得多**。你得小心地展開，確定你看到全部的問題。

請你求解這張問題表，**當你將所有問題的解加總，得到多少？**
