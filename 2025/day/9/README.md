## 第九日：電影院
你從遊樂場一角滑下緊急出勤桿，降落在北極總部的電影院！

這座電影院鋪著滿地的大格子地磚，排程有趣的形狀。小精靈們正忙著裝飾著觀影廳，更換這些地磚的一些方形磚塊。有些磚塊是**紅色的**。小精靈們想要找出最大的長方形，將兩個對角線之間鋪上紅色磚塊。她們甚至開了一張清單 (如你的輸入檔)，寫出所有紅色磚塊所在的位置。

以下為例：

```
7,1
11,1
11,7
9,7
9,5
2,5
2,3
7,3
```

將紅色磚塊標示為` # `，而其他磚塊標示為` . `。紅色磚塊的鋪排，看起來像這樣子：

```
..............
.......#...#..
..............
..#....#......
..............
..#......#....
..............
.........#.#..
..............
```

你能選擇任兩個紅色磚塊，視為一個長方形的對角線。你的任務是要盡量找到最大的長方形。

例如，你做出一個長方形 (以` O `標示)，位於` 2,5 `與` 9,7 `兩個磚塊之間的` 24 `格範圍：

```
..............
.......#...#..
..............
..#....#......
..............
..OOOOOOOO....
..OOOOOOOO....
..OOOOOOOO.#..
..............
```

或者，你找到在` 7,1 `與` 11,7 `之間的` 35 `格範圍的長方形：

```
..............
.......OOOOO..
.......OOOOO..
..#....OOOOO..
.......OOOOO..
..#....OOOOO..
.......OOOOO..
.......OOOOO..
..............
```

當你找到在` 7,3 `與` 2,3 `之間的` 6 `格範圍的長方形，是一個比較扁的長方形：

```
..............
.......#...#..
..............
..OOOOOO......
..............
..#......#....
..............
.........#.#..
..............
```

最終你能找到最大的長方形佔了` 50 `格，其中一種方式是找到在` 2,5 `與` 11,1 `之間範圍：

```
..............
..OOOOOOOOOO..
..OOOOOOOOOO..
..OOOOOOOOOO..
..OOOOOOOOOO..
..OOOOOOOOOO..
..............
.........#.#..
..............
```

你用兩個紅色磚塊為對角，**能找出的最大長方形是多大？**
